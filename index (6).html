Componenta Hardware
a unui sistem de calcul

Hardware-ul reprezintă totalitatea componentelor fizice ale unui calculator. Fiecare componentă are un rol precis în funcționarea sistemului — de la prelucrarea datelor până la afișarea rezultatelor.

Cunoașterea arhitecturii unui sistem de calcul este esențială pentru alegerea configurației potrivite, depanarea problemelor și înțelegerea modului în care software-ul interacționează cu hardware-ul.

Componente principale
  • Unitatea Centrală de Procesare (CPU)
  • Memoria RAM și ROM
  • Dispozitive de stocare (HDD, SSD)
  • Placa de bază (Motherboard)
  • Placa video, sunet, rețea
  • Periferice de intrare și ieșire
  • Sursa de alimentare

Memoria RAM

Random Access Memory
  • ⚡
    Volatilă — datele se pierd la oprirea curentului
  • 🔀
    Acces aleator — orice locație accesibilă direct, fără parcurgere
  • 🚀
    Viteza mare — mult mai rapid decât HDD/SSD
  • 📋
    Rol — stochează datele și programele active (în rulare)
  • 📏
    Capacitate tipică — 8GB, 16GB, 32GB
  • 🔄
    Tip modern — DDR4, DDR5

Memoria ROM

Read Only Memory
  • 🔒
    Non-volatilă — datele se păstrează și fără curent electric
  • 📖
    Doar citire — în mod normal nu poate fi modificată de utilizator
  • 🐢
    Capacitate mică — câțiva MB, nu GB
  • 📋
    Rol — stochează firmware-ul (BIOS/UEFI), instrucțiunile de pornire
  • 🔧
    Conținut — POST, bootstrap loader, setări hardware de bază
  • ⚙️
    Modern — EEPROM, Flash ROM (poate fi actualizat prin software)

Componenta Software
a unui sistem de calcul

Software-ul reprezintă totalitatea programelor, aplicațiilor și datelor care rulează pe hardware. Fără software, hardware-ul este o colecție de componente electronice fără utilitate practică.

Sistemul de operare este componenta software esențială care gestionează resursele hardware și oferă o interfață între utilizator și calculator.

Tipuri de software
  • Software de sistem (SO, drivere, firmware)
  • Software de aplicație (Word, Chrome)
  • Software utilitar (antivirus, arhivare)
  • Software open source (Linux, LibreOffice)
  • Software proprietar (Windows, Adobe)
  • Firmware (BIOS/UEFI, software integrat)
🖥️

Software de sistem

Gestionează direct hardware-ul. Include sistemul de operare, drivere de dispozitive și firmware. Este baza pe care rulează restul.

Ex: Windows, Linux, macOS
📝

Software de aplicație

Programe care îndeplinesc sarcini specifice pentru utilizator. Rulează deasupra sistemului de operare.

Ex: Word, Chrome, Photoshop
🔓

Open Source

Codul sursă este public și poate fi modificat liber. Gratuit, transparent, susținut de comunitate. Pro: cost zero. Contra: suport tehnic mai dificil.

Ex: Linux, LibreOffice, VLC
🔒

Software proprietar

Codul sursă este secret, protejat de licență. De obicei contra cost. Pro: suport oficial, stabilitate. Contra: cost, dependență de producător.

Ex: Windows, Office, Adobe

Securizarea sistemului de operare

Protecția unui sistem de calcul implică mai multe niveluri. Click pentru detalii.

01

Firewall — Zidul de protecție al rețelei

Rețea ▼

Firewall-ul monitorizează și controlează traficul de rețea — ce poate intra și ieși din calculator. Acționează ca un filtru între rețeaua locală și internet.

Tipuri: firewall software (integrat în Windows, firewall dedicat) și firewall hardware (router cu funcție de firewall).

Ce face practic: blochează conexiunile nesolicitate, previne accesul hackerilor, permite aplicațiilor autorizate să comunice liber.

Verificare în Windows: Control Panel → System and Security → Windows Defender Firewall.

02

Software Antivirus — Protecția împotriva malware

Malware ▼

Un antivirus detectează, blochează și elimină software-ul malițios (malware): viruși, troieni, ransomware, spyware, adware.

Tipuri de malware:

  • Virus — se atașează la fișiere și se auto-replică
  • Troian — se deghizează ca program legitim
  • Ransomware — criptează fișierele și cere răscumpărare
  • Spyware — colectează date fără știrea utilizatorului

Esențial: antivirusul trebuie actualizat constant — noile amenințări apar zilnic.

03

Gestionarea utilizatorilor și permisiunilor

Acces ▼

Un sistem de operare poate avea mai mulți utilizatori cu drepturi diferite. Principiul „minim necesar" — fiecare utilizator primește exact drepturile de care are nevoie, nu mai mult.

Tipuri de conturi:

  • Administrator — acces complet, poate instala programe, modifica sistem
  • Utilizator standard — poate folosi aplicații, nu poate modifica setările sistemului
  • Guest — acces limitat, fără salvarea setărilor

Bună practică: folosește cont standard pentru activitățile zilnice; contul de administrator doar când instalezi ceva.

04

Criptarea datelor — protecție la furt fizic

Criptare ▼

Criptarea transformă datele în format ilizibil fără cheia corectă. Chiar dacă laptopul e furat, datele rămân protejate.

BitLocker (Windows) — criptează întregul disc. Dacă laptopul e furat, datele nu pot fi accesate fără parola de criptare.

FileVault (macOS) — echivalentul BitLocker pentru Mac.

LUKS (Linux) — soluție de criptare pentru distribuțiile Linux.

Scenariu practic: Laptop necriptat furat → hacker scoate SSD-ul și citește toate datele. Laptop criptat furat → datele sunt inaccesibile.

Activitate practică 01

Monitorizare procese cu Task Manager

Utilizează Task Manager pentru a identifica aplicațiile care consumă cel mai mult RAM și CPU.

  1. Apasă Ctrl + Shift + Esc sau click dreapta pe bara de sarcini
  2. Mergi la tab-ul Procese (Processes)
  3. Click pe coloana CPU pentru sortare descrescătoare
  4. Identifică procesul cu cel mai mare consum
  5. Notează numele, consumul CPU% și RAM (MB)
  6. Fă o captură de ecran ca dovadă
Activitate practică 02

Verificarea securității sistemului

Verifică dacă sistemul tău are toate măsurile de securitate active.

  1. Deschide Windows Security (Start → Windows Security)
  2. Verifică că Virus & threat protection este activ și actualizat
  3. Verifică că Firewall & network protection este pornit
  4. Verifică Device security pentru criptare
  5. Completează un checklist cu ce este activ / inactiv

Introducere în Inteligența Artificială

🧠
Ce este IA?

Sisteme software care „învață" din date și pot face predicții sau genera conținut fără instrucțiuni explicite pentru fiecare situație.

📊
Tipuri de IA

Clasificare, predicție, recomandare, generare de conținut, recunoaștere de imagini/voce, interacțiune cu mediul (robotică).

💬
Modele LLM

Large Language Models (ChatGPT, Gemini, Copilot) generează text probabilistic bazat pe miliarde de exemple de antrenament.

⚠️
Limitări & Riscuri

Bias (părtinire), halucinații (informații false prezentate cu încredere), drepturi de autor, dezinformare, consum energetic ridicat.

✍️
Prompt eficient

Instrucțiune clară care include: rol, context, cerință specifică, format dorit. Ex: „Acționează ca profesor de fizică și explică..."

🔍
Gândire critică

Verifică întotdeauna informațiile generate de IA din surse de încredere. IA poate „halucineze" referințe și fapte inexistente.

Neticheta — regulile comunicării digitale civilizate

La fel cum există reguli de politețe în viața reală, există norme pentru spațiul digital.

01

E-mail profesional — cum se scrie corect

E-mail ▼

Structura unui e-mail profesional:

  • Subiect (Subject) — clar și specific: „Cerere orar consultații — Popescu Ion, clasa 9A"
  • Salut formal — „Stimate domnule profesor," / „Bună ziua,"
  • Corpul mesajului — concis, la obiect, fără prescurtări (nu „u" în loc de „vă")
  • Încheierea — „Cu respect," / „Cu stimă,"
  • Semnătura — nume complet, clasa, școala

Greșeli frecvente: subiect gol, limbaj argotic, scriere cu majuscule (înseamnă „țipăt" online), fără salut/semnătură.

02

Identificarea mesajelor cu risc — Phishing

Securitate ▼

Phishing = tentativa de a obține date personale (parole, date bancare) prin mesaje false care imită instituții legitime.

Semnale de alarmă:

  • Adresă de e-mail suspectă (nu de pe domeniu oficial)
  • Urgență artificială: „Contul tău va fi ÎNCHIS în 24 ore!"
  • Linkuri care nu corespund textului (hover pentru verificare)
  • Greșeli de ortografie și gramaticale
  • Cereri de parole sau date bancare prin e-mail
  • Atașamente neașteptate de la expeditori necunoscuți

Regulă de aur: Nicio bancă, instituție sau platformă legitimă nu îți va cere parola prin e-mail.

03

Tehnologii emergente — VR și AR

Emergent ▼

Realitatea Virtuală (VR) — înlocuiește complet mediul real cu unul virtual. Necesită ochelari/căști VR. Exemple: Meta Quest, simulatoare de pilotaj, tururi virtuale.

Realitatea Augmentată (AR) — suprapune elemente digitale peste lumea reală. Vizibil prin telefon sau ochelari AR. Exemple: Pokémon GO, filtrele Instagram, instrucțiuni de montaj.

Realitatea Extinsă (XR) — termen umbrelă care include VR, AR și Mixed Reality (MR).

Aplicații educaționale: tururi virtuale în muzee, simularea experimentelor periculoase, anatomie 3D interactivă, studiul istoriei „la fața locului".

Activitate practică 03

Crearea unui prompt eficient pentru IA

Exersează interacțiunea cu un chatbot pentru a obține rezultate de calitate.

  1. Deschide ChatGPT sau Gemini (cont gratuit)
  2. Scrie un prompt slab: „Explică fotosinteza"
  3. Notează calitatea răspunsului
  4. Scrie un prompt bun cu rol + context + format: „Ești profesor de biologie pentru clasa a IX-a. Explică fotosinteza în 5 puncte simple, cu un exemplu practic pentru fiecare."
  5. Compară cele două răspunsuri și documentează diferențele
Activitate practică 04

Fact-checking răspuns generat de IA

Verifică dacă informațiile generate de IA sunt corecte și de încredere.

  1. Cere unui chatbot 5 fapte despre un subiect știintific
  2. Verifică fiecare fapt pe Wikipedia și o sursă academică
  3. Identifică eventualele „halucinații" (informații false)
  4. Creează un tabel: Fapt IA | Corect/Incorect | Sursa verificată
  5. Prezintă concluziile clasei

Conținuturi Digitale

Crearea și prelucrarea documentelor digitale (texte, prezentări) este o competență fundamentală în lumea modernă. Formatarea profesională, coerența vizuală și adaptarea la publicul țintă sunt esențiale.

Conținuturi acoperite
  • Documente text profesionale
  • Prezentări digitale interactive
  • Formatare avansată (stiluri, cuprins)
  • Colaborare în documente (Track Changes)
  • Îmbinare corespondență (Mail Merge)
  • Utilizarea responsabilă a IA în birotică

Contrast vizual

Text întunecat pe fundal deschis (sau invers). Raport minim 4.5:1 pentru accesibilitate. Evită: text gri pe fundal gri.

Design
⚖️

Echilibru și aliniere

Elementele trebuie aliniate pe o grilă. Spațiu negativ (alb) egal în jur. Nu: text și imagini împrăștiate aleatoriu.

Layout
🔤

Ierarhie tipografică

Titlu mare → Subtitlu mediu → Conținut mic. Maxim 2-3 fonturi per document. Evită: mai mult de 3 dimensiuni diferite pe același slide.

Tipografie
🎯

Regula 6×6

Maxim 6 rânduri per slide, maxim 6 cuvinte per rând. Slide-urile nu sunt un document Word — mai puțin = mai bine.
